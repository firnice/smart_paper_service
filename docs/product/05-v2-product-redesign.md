# 05 - V2 产品重设计方案

## 版本信息

- **文档编号**: 05
- **创建日期**: 2026-03-27
- **阶段**: 产品重设计（前端交互重组 + 功能增强）

## 背景

Smart Paper V1 经过 Phase 1-4 的迭代，已具备完整的后端能力（OCR、变式题、错题管理、统计分析、趋势分析、导出打印）。但前端交互存在以下问题：

1. **页面分散** — 首页（纯统计）、工作台、错题本、打印、我的 共 5 个 tab，功能重叠
2. **核心动作隐藏** — 录入错题的入口不够突出，用户需要多次点击才能到达
3. **缺少训练闭环** — 记录了错题但缺乏系统化的练习回归机制

V2 的核心目标是：**以工作台为中心，降低录入门槛，打通训练闭环**。

## 角色体系

### 1. 管理员（家长/教师）

| 功能模块 | 说明 |
|----------|------|
| 学生列表 | 查看绑定的学生，查看学习概况 |
| 统计分析发起 | 手动触发 LLM 趋势分析报告（已有 `/api/analysis/trend`） |
| 模型设置 | Agent 配置管理（已有 `/api/admin/agents`） |

### 2. 学生

核心角色，V2 重设计重点。

## V2 页面架构

### 导航结构（底部 Tab）

```
┌─────────────────────────────────────────┐
│                                         │
│              [页面内容区]                │
│                                         │
├────────┬──────────┬─────────┬───────────┤
│ 工作台  │          │         │   我的    │
│  📋    │   [+📷]  │         │   👤     │
│        │  中央按钮  │         │          │
└────────┴──────────┴─────────┴───────────┘
```

- **工作台** — 错题列表 + 简单统计（核心页面）
- **中央录入按钮** — 拍照/选图录入错题（突出的圆形按钮）
- **我的** — 个人信息 + 统计展示 + 消息

> 从 5 个 tab 精简到 2+1（工作台、我的 + 中央录入），大幅降低认知负担。

### 2.1 工作台（核心页面）

#### 2.1.1 简单统计展示（顶部）

位于页面顶部，展示关键指标：

- 错题总数
- 未掌握数
- 本周新增数
- 掌握率趋势（迷你折线图）

#### 2.1.2 错题列表

**卡片展示内容：**

| 元素 | 说明 |
|------|------|
| 题目文本 + 图片 | 题目在上，图片在下 |
| 原题照片链接 | 点击可查看原始拍照图片 |
| 掌握状态 | 已掌握(绿) / 未掌握(红) 标签 |
| 学科 + 学期 | 标签形式展示 |
| 操作按钮 | 掌握标记、快速训练 |

**筛选功能：**

| 筛选维度 | 说明 |
|----------|------|
| 掌握状态 | 全部 / 已掌握 / 未掌握 |
| 学科 | 数学 / 语文 / 英语 等 |
| 学期 | 默认当前学期（如"三年级上"），可切换 |

#### 2.1.3 单条操作

- **掌握标记** — 一键切换掌握/未掌握状态
- **快速训练** — 弹出训练选项
  - **单条打印** — 仅打印该题
  - **举一反三** — 调用 `/api/variants/generate-for-question`，生成同类型题目
    - 展示生成的变式题题目
    - 可选择打印变式题

#### 2.1.4 笔记本操作（批量）

**重新练习（批量回归）：**

```
重新练习
├── 人工选择
│   └── 用户自由勾选要练习的题目
└── 随机选择
    ├── 全部未掌握（打乱顺序）
    └── 自定义数量（如：随机 10 题）
```

选择完成后 → 生成练习卷 → 可打印 PDF

### 2.2 中央录入按钮

底部导航栏中央的突出按钮，点击后进入录入流程：

#### 录入方式

- **从相册选择** — 选择已有照片
- **拍照** — 调用相机拍摄

#### 识别流程

```
拍照/选图
    ↓
框选识别区域（裁剪）
    ↓
OCR 识别题目（/api/ocr/extract）
    ↓
选择题目数量
├── 单题模式 — 整张图为一道题
└── 多题模式 — 图中包含多道题，分别识别
    ↓
LLM 分析（/api/ocr/analyze-question）
├── 自动识别学科
├── 自动识别错误类型（如有）
├── 自动匹配学期
├── 自动提取知识点（按地区教材归类）
└── 生成解题思路
    ↓
用户确认/修改
    ↓
保存错题（/api/wrong-questions）
```

#### 阻塞交互

OCR 识别和 LLM 分析期间，使用蒙版（`.student-composer-overlay`）阻塞用户操作，展示进度提示。

### 2.3 我的

- **顶部** — 用户头像、姓名、年级
- **消息** — 红点提示（分析报告完成等通知）
- **退出登录**
- **统计展示**
  - 错题总数
  - 已掌握 / 未掌握比例
  - 按学科分布饼图
  - 按学期、错误类型的分析结果
  - 趋势分析报告入口

## 现有后端能力映射

| V2 功能 | 已有 API | 是否需要改动 |
|---------|----------|-------------|
| 错题列表 | `GET /api/wrong-questions` | 可能需增加组合筛选参数 |

| 快速训练-打印 | `POST /api/export` | 无需改动 |
| 举一反三 | `POST /api/variants/generate-for-question` | 无需改动 |
| 录入-OCR | `POST /api/ocr/extract` | 无需改动 |
| 录入-分析 | `POST /api/ocr/analyze-question` | 可能需增加地区参数 |
| 统计总览 | `GET /api/statistics/overview` | 无需改动 |
| 学科统计 | `GET /api/statistics/by-subject` | 无需改动 |
| 趋势分析 | `POST /api/analysis/trend` | 无需改动 |
| 批量回归 | 无 | **需新增**：批量生成练习卷接口 |

## 与 V1 的差异对比

| 维度 | V1 | V2 |
|------|----|----|
| 导航 | 5 个 tab | 2+1（工作台 + 我的 + 中央录入） |
| 首页 | 纯统计页 | 取消，统计移入工作台顶部和"我的" |
| 录入入口 | 工作台内的按钮 | 底部导航中央突出按钮 |
| 错题本 | 独立页面 | 合并到工作台 |
| 打印 | 独立页面 | 融入快速训练和批量回归流程 |
| 训练机制 | 仅有练习重做 | 增加批量回归（人工/随机选择） |

## 多模型评价综合

### 评价 1（外部模型）

**肯定点：**
- 工作台中心化设计正确
- 中央录入按钮降低操作门槛
- 批量回归覆盖主要学习场景
- 举一反三是"智能"的核心体现

**建议：**
1. 管理员增加"下发练习任务" → **暂缓到 Phase 3**
2. 增加掌握程度五星/遗忘曲线 → **推荐实施**，数据模型已支持
3. 批量回归后一键生成 PDF → **推荐实施**，导出 API 已就绪
4. 后端基本不需大改，前端需较多 Layout 重构 → **准确**

### 评价 2（Claude Opus 分析）

**额外发现：**
1. `StudentDashboardPage.jsx` 2960 行过长，需拆分为子组件
2. 现有路由 5→3 的精简需要重构 `App.jsx`
3. 后端接口 90% 就绪，仅需微调筛选参数和新增批量练习卷接口
4. 知识点按地区归类方案需谨慎，建议先做通用版

**风险提示：**
- 前端重构涉及文件多、改动大，建议分阶段推进（先路由 → 再布局 → 再功能）
- 中央录入按钮在移动端体验好，但 Web 端需要适配考虑

## 实施计划

### Phase V2-1: 路由重构和页面精简

- 移除 `/home`（首页）路由
- 移除 `/bank`（题库）路由，功能合并到工作台
- 重构 `/student/dashboard` 为新版工作台
- 重构 `/profile` 为新版"我的"
- 将录入功能改为全局浮窗/弹窗

### Phase V2-2: 工作台核心功能

- 拆分 `StudentDashboardPage.jsx` 为子组件
- 实现新版错题卡片组件
- 实现筛选栏组件
- 实现顶部统计区域
- 实现单条操作（掌握标记、快速训练）

### Phase V2-3: 批量回归和训练闭环

- 实现批量选择 UI（人工选择 + 随机选择）
- 对接导出 API 生成练习卷
- 实现举一反三变式题展示

### Phase V2-4: 统计和个人中心

- 实现新版"我的"页面
- 整合统计图表
- 实现消息通知功能
