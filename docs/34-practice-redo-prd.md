## Problem
- 当前"重做"依赖打印纸质卷子，无法追踪结果和掌握程度。
- 一张卷子操作麻烦，用户体验差。
- 缺少"举一反三"练习方式，学生无法在同类题型上强化训练。
- 错题状态（新错题/复习中/已掌握）切换不便，缺少快速标记入口。

## Goals
- 在错题本页面提供在线原题重做功能，做完立即记录结果并更新状态。
- 提供 LLM 驱动的"举一反三"功能，根据原题生成 2-3 道类似题目。
- 提供快速标记掌握状态功能，一键切换。
- 将打印功能集成到错题本页面，减少页面跳转。

## Success Metrics
- 学生可在 3 次点击内完成一道错题的重做和结果记录。
- 举一反三生成的题目质量：与原题同类型、同难度（人工抽检通过率 >= 85%）。
- 快速标记掌握后，统计数据实时更新。

## Scope
- In scope:
  - 原题重做弹窗（显示题目 → 标记结果 → 更新状态）。
  - 批量多选重做（选中多题 → 依次做题 → 汇总）。
  - 举一反三（LLM 生成类似题 → 逐题练习）。
  - 快速标记掌握（错题列表卡片上的状态切换）。
  - 打印入口集成到错题本。

- Out of scope:
  - 在线答题（手写识别、自动批改）。
  - 举一反三题目的持久化存储（本期为临时生成，不入库）。
  - 举一反三的做题结果追踪（本期仅记录原题的学习状态）。

## User Stories

### 原题重做
- 作为学生，我想选一道错题后在线查看原题，做完后标记"做对了"或"做错了"。
- 作为学生，我想批量选多道错题一起重做，系统依次出题，最后看汇总结果。

### 举一反三
- 作为学生，我想对一道错题生成类似题目，帮助我巩固同类知识点。
- 作为学生，我想看到类似题的参考答案和解题提示。

### 快速标记
- 作为学生/家长，我想在错题列表上直接点一下就能标记某题"已掌握"。
- 作为学生，我想看到标记后统计数据（掌握率等）立即更新。

### 打印集成
- 作为家长，我想在错题本中选好题目后直接进入打印页面。

## Acceptance Criteria
1. 错题卡片显示 [重做] [举一反三] [标记掌握] 操作入口。
2. 重做弹窗展示题目文字和图片，提供 [做对了 ✓] [做错了 ✗] [跳过] 三个按钮。
3. 点击结果按钮后创建 study_record，更新错题 status 和 review_count。
4. 举一反三点击后调用 LLM 生成 2-3 道类似题，展示在弹窗中。
5. 每道生成题显示题目文本、参考答案（可折叠）、解题提示。
6. 快速标记支持 new ↔ reviewing ↔ mastered 三态切换。
7. 多选模式下可选择多题进入批量重做。
8. 错题本增加"打印选中"入口，跳转到 PrintPage 并预选。
