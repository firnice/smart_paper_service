# Raw 来源说明

`raw/` 用来放原始来源快照，不放高层综合结论。

## 适合放在这里的内容

- 外部文章、gist、tweet、规范文档的摘录式快照
- 仓库某次初始化或调研时的来源清单
- 一次会话里产生、但仍然更像“source material”的结构化记录

## 规则

- 文件名使用 `YYYY-MM-DD-topic.md`。
- 尽量 append-only；旧条目只做小的事实修正。
- 如果原始材料已经在 repo 里，优先链接到原文件，不复制整篇正文。
- 每个 raw 文件都应注明来源链接或本地来源路径。
- 从 raw 向 wiki 综合时，应该更新 `index.md` 和 `log.md`。
